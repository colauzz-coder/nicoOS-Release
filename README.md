# nicoOS

A 32-bit operating system written in C++ & Assembly from scratch by myself with no AI.

# How to test it
1. Download the latest `nico_os.img` file from the **[Releases](../../releases)** page.
2. Open your terminal and run it using **QEMU**:

\`\`\`bash
qemu-system-i386 -drive format=raw,file=nico_os.img
\`\`\`
